# Original soundtrack

CHECKOUT OF HELL uses project-owned music composed specifically for the game. No Doom, Freedoom, Star Wars or other commercial soundtrack material is copied into the project.

## Current department themes

- `D_COH01.mid` — **Closing Time — Empty Aisles**. A slow, sparse empty-store cue built from two-bar drones, distant vibraphone phrases and occasional checkout-like chimes. It deliberately leaves large gaps so weapon, enemy and Overtime telegraphs stay readable.
- `D_COH02.mid` — **Warehouse 13.5 — Forklift Graveyard**. A darker low-register cue with restrained machinery-like percussion and a colder repeating motif for the warehouse and Regional Manager route.
- `D_COH03.mid` — **Frozen Foods — Compressor Choir**. Thin high-register chimes sit over slow cold-storage drones and very restrained compressor-like percussion, keeping the freezer department distinct without masking warning cues.
- `D_COH04.mid` — **Electronics — Dead Pixel Choir**. Sparse digital-feeling chime clusters, uneasy pad movement and tiny machine-like percussion accents give the display aisles a haunted showroom identity without covering scanner, warning or demo-wall surge cues.
- `D_COH05.mid` — **Customer Service — Please Hold Forever**. A deliberately too-polite hold-music motif keeps slipping over low uneasy drones, sparse service-bell chimes and tiny office-machine percussion so the refund queue feels corporate, empty and wrong without masking the twelve-second audit waves.

All five tracks are deterministic Standard MIDI files generated by `tools/generate_music_assets.py` using only Python's standard library. They are generated during every normal build and packaged under the PK3 `music/` namespace. MAPINFO gives each currently playable department its own project-owned `D_COH01` through `D_COH05` lump instead of sharing an inherited or neighboring department theme.

## Why MIDI

The current prototype uses authored MIDI rather than shipping a large rendered audio file. This keeps the repository and portable development package small, avoids adding an audio-encoder dependency to the build, and lets GZDoom use its normal legal runtime synth path. The composition data itself is entirely original to this project.

The arrangements intentionally avoid dense action-music layering. CHECKOUT OF HELL relies on combat sound, PA warnings and Overtime hazard telegraphs for gameplay readability, so the soundtrack acts as creepy workplace atmosphere rather than competing with those cues.

## Build and validation

Run:

```text
python tools/build.py
python tools/test_music_contract.py
```

The soundtrack regression contract verifies:

- deterministic regeneration,
- valid single-track Standard MIDI headers,
- tempo and clean end-of-track metadata,
- department-specific track-name markers,
- one distinct authored soundtrack mapping for every currently playable department,
- removal of inherited base-game music references,
- inclusion of all generated department tracks in the packaged PK3.

The pinned Windows GZDoom runtime smoke test then parses the packaged MAPINFO and music namespace as part of CI.

## Expansion rule

New department music is added only when that department has real playable content. Future tracks should preserve the same priorities: original composition, readable combat mix, restrained file size and deterministic/reproducible build output.
